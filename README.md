## About

Landing page for an ice cream shop. Adaptive design, modal windows, mobile menu,
Swiper slider.

## Tech stack

- HTML / SCSS (BEM)
- JavaScript (vanilla)
- Parcel (bundler)
- Swiper (reviews slider)
- Modern normalize
- PostHTML (includes)

## Preview

**Live demo:**
[Himadieiev.github.io/ice-cream-new](https://Himadieiev.github.io/ice-cream-new)

## Quick start

```bash
git clone https://github.com/Himadieiev/ice-cream-new.git
cd ice-cream-new

npm install

npm start

npm run build
```
